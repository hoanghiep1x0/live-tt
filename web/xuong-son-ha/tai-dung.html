Mọi thứ trong Sơn Hà dựa trên quy ước tên file: code không cần biết file nào tồn tại, chỉ dò theo tên. Có file thì dùng, chưa có thì lùi về bậc kế tiếp. Theo đúng quy ước này thì thêm nhân vật, thêm trang phục hay dựng hẳn một game khác chỉ là sản xuất tài nguyên rồi chép vào đúng chỗ.

3. Cấu trúc thư mục

Cây thư mụcclient/designs/<game>/ src/loi/ ← luật + dữ liệu thuần (không DOM, không Date.now, không Math.random) src/ve3d/ ← vẽ: ghép lớp, cảnh thử, chiêu (DOM + three.js) assets/ nhan-vat/ ← tranh + video nhân vật (<nv>-<áo>…, chien-…) nen/ ← tranh nền, video nền (-dong.mp4), tiền cảnh (-truoc.webp) chieu/ ← tranh chiêu công pháp vp/ ← icon món fx/, yeu/, than/ … web/<game>/tranh-goc/ ← ảnh gốc độ phân giải cao, video Muse gốc, ảnh nền xanh, ảnh soát web/<game>/cong-cu/ ← nv-video.py, nen-muse.py, tien-canh.py, cat-luoi.py, chieu-cp.py web/xuong-<game>/ ← trang bản thiết kế này (dữ liệu sinh bằng cong-cu/xuat-du-lieu.mjs)

4. Thứ tự dựng một game mới

  1. Sổ phong cách: một tranh mẫu phong cách (mau-phong-cach.jpg), bảng màu từng phe, những thứ cấm (Sơn Hà: không rồng Tàu, không chữ Hán).
  2. Năm bảng dữ liệu (§1) viết bằng code thuần trước, chưa cần hình.
  3. Tranh nền từng màn (ChatGPT), cùng khổ 1024×1536, chừa giữa sân trống cho nhân vật.
  4. Video nền (Muse → nen-muse.py) và tiền cảnh (tien-canh.py).
  5. Nhân vật gốc mỗi phe × giới, rồi tranh dáng thiền và dáng chiến cho từng trang phục.
  6. Video nhân vật: thiền + công + thủ + hồi (Muse nền xanh → nv-video.py).
  7. Chiêu thức, icon, hiệu ứng vật phẩm.
  8. Kịch bản sự kiện: viết dòng thời gian như trang Kịch bản trước, rồi mới code.
  9. Soát theo bảng soát, chạy xuat-du-lieu.mjs xem tiến độ.

5. Thêm nhân vật / trang phục vào Sơn Hà

Thêm một trang phục (ví dụ T10)

  1. loi/tang-bao.ts: thêm dòng vào AO (tên hai phe, giá, cảnh giới, tranh: 'c10').
  2. loi/the-gioi.ts: thêm 'c10' vào cuối DUOI_AO.
  3. Làm cho cả 4 nhân vật: tranh thiền, tranh chiến, 4 video (quy trình).
  4. Sửa bảng giá trong docs/phong/tu-tien/ban-do.md §3b cho khớp, chạy test tests/client/designs/tu-tien-son-ha.
  5. Chạy xuat-du-lieu.mjs: Danh mục tự có thêm cột T10.

Thêm một nhân vật (ví dụ nhân vật thứ ba của Sơn Tông)

  1. Chọn id file (ví dụ son-gia), thêm vào NHAN_VAT trong web/xuong-son-ha/cong-cu/xuat-du-lieu.mjs.
  2. Code chọn tranh (duongTranh, tenNv trong loi/the-gioi.ts) nhận thêm giới hoặc kiểu mới.
  3. Vẽ nhân vật gốc, rồi 9 tranh thiền + 9 tranh chiến (gửi kèm nhân vật gốc để giữ mặt).
  4. 36 video (9 áo × thiền, công, thủ, hồi).

6. Đoạn code ghép lớp dùng lại được

Đổi video của một lớp mà không có khung trống: video mới nạp ngầm, chờ canplay, hiện đè lên video cũ cùng một chớp sáng ngắn rồi mới bỏ video cũ. Đặt currentTime ngẫu nhiên để nhiều người không thở cùng nhịp.

JavaScript · đổi video lớp nhân vật/** Đổi video trong khối lớp `o` sang `src`; chưa có video thì dùng tranh dự phòng. */ function doiVideo(o, src, duPhong, { lap = true, chop = true } = {}) { const cu = o.querySelector('video, img'); const v = document.createElement('video'); v.muted = v.defaultMuted = true; // bắt buộc gán thuộc tính thì trình duyệt mới cho tự phát v.playsInline = true; v.loop = lap; v.className = cu?.className ?? ''; v.style.opacity = '0'; v.onerror = () => { // không có file → tranh tĩnh của chính bộ áo đó const im = new Image(); im.className = v.className; im.src = duPhong; v.replaceWith(im); cu?.remove(); }; v.addEventListener('canplay', () => { if (lap) v.currentTime = Math.random() * (v.duration || 1); // lệch pha mỗi người v.play(); v.style.opacity = '1'; if (chop) v.animate([{ filter: 'brightness(2.6)' }, { filter: 'brightness(1)' }], { duration: 450, easing: 'ease-out' }); setTimeout(() => cu?.remove(), 250); // cũ nằm dưới thêm 0,25 s để không lộ khung trống }, { once: true }); v.src = src; o.append(v); }
